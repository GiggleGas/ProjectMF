## 一、任务清单（按依赖顺序整理）

### MVP —— 目标：跑通「进图 → 采集/捕捉/做任务 → 撤离带出 或 打 Boss」

| # | 任务 | 内容 | 依赖 | 状态 |
|---|---|---|---|---|
| M1 | **掉落物系统（loot）** | 通用掉落表 DataAsset；怪/采集点掉落生成 → 拾取进 `UMFInventoryComponent.ResourceSlots`；来源标记（局内新获） | 无（独立起手） | ⬜ 起手 |
| M2 | **任务/目标系统** | 进图标记 N 处目标点；MVP 最简形态「到点操作 N 处」；全部完成 → 解锁出口 | 无（与 M1 可并行） | ⬜ |
| M3 | **大地图铺设** | 手工大平图 ×1；复用 `AMFSpawnAIManager` 散点铺怪/资源点/Boss 洞 | 无（内容向，可并行） | ⬜ |
| M4 | **元层 P1：持久核心** | `UMFSaveGame` + `UMFMetaSettings` + `UMFMetaSubsystem`（Save/Load/StartNewGame/boot 读档/调试 exec）。方案已定（3 步），照案开工 | P0✅ | ⬜ |
| M5 | **元层 P2：入局传输** | `SeedPetsFromInstances()` + `BroughtInIDs` 来源标记 | M4 | ⬜ |
| M6 | **元层 P4：启动编排** | 出征写 `PendingLoadout`+seed → OpenLevel → 大地图 GameMode BeginPlay 种入交棒（v3 无生成器桩，直接进手工图） | M4、M5 | ⬜ |
| M7 | **元层 P5：回收落盘** | `ReconcileExtraction`（存活更新/新增、带入阵亡进墓碑、通关发复活道具）；阵亡瞬间立即存 | M4 | ⬜ |
| M8 | **撤离 / 打 Boss 二选一出口** | 任务完成后出口分支：撤离 → 走 P5 结算交接；打 Boss（MVP 用固定 Boss 洞，复用现有 Boss）→ 胜利结算 | M2、M7 | ⬜ |
| M9 | **元层 P3：局外 UI** | 主菜单 → 仓库/编队 → 出征；结算界面；墓碑/复活道具入口（可先简版占位，后美化） | M4–M7 | ⬜ |
| M10 | **MVP 全流程联调** | 主菜单→编队→进图→采集/捕捉/任务→撤离或打Boss→结算写档→回主菜单，闭环验收 | 全部 | ⬜ |

### P2 期 —— 目标：解锁进度 + 劳作 + 威胁 Boss

| # | 任务 | 内容 | 依赖 |
|---|---|---|---|
| S1 | **大陆/阶段解锁进度** | SaveGame 增量：4 大陆 × 多阶段 + Boss 门；击败 Boss → 回局外解锁下一阶段入口；局外选关 UI | MVP |
| S2 | **游荡破坏 Boss AI** | 献祭/时间/任务触发降生 → 场景游荡 + 破坏；替换 MVP 的固定 Boss 洞形态 | MVP |
| S3 | **局内宠物劳作** | 非出战宠派到采集点/工作点 → 任务辅助 + 囤物资 | M1、MVP |
| S4 | **局外宠物劳作（放置产出）** | 派仓库宠到已通关阶段挂机产出；产速/效率 per 阶段；SaveGame 增量：派遣分配 | S1、S3 |

### 排期说明
- **A1.5 背包 + A1.7 任务系统插入**（用户 2026-07-03 追加）：背包=饥荒式格子+堆叠上限（排 A1 后、B1 前，数据模型定型再序列化存档）；任务系统=DataTable 配置的统一目标追踪层（排 A2 前，目标点作为其一种类型接入）。两项共挤掉约 1 周，MVP 闭环从"~7 月底"顺延为"8 月初"。
- **A1 起手**符合既定决策（先掉落物）；A2/A3 与元层无依赖，可穿插做换脑子。
- **M8 撤离必须排在 M7 之后**（撤离结算走 `PendingExtraction`），这是元层插队进 MVP 中段的原因。
- **MVP 打 Boss 先用固定 Boss 洞**（复用现有 Boss + 全灭判负），游荡/降生形态留给 S2，避免 MVP 被 Boss AI 拖住。
- 参考近期速度（6/26–7/01 完成 6 个 gameplay 特性），此排期偏保守；若顺利 MVP 可提前至 W3 末。
- 待细化项（任务类型、消耗模型、献祭配方、产出公式、大陆节奏）按提案 §7 在对应任务开工时定，不单独占期。
