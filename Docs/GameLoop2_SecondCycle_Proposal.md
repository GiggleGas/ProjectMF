# 第二循环策划案 ——「开放生存 + 大陆阶段解锁 + 宠物劳作」

> 状态：草案 v3（2026-06-29，局内由地牢重做为开放生存大地图）
> 演变：v1 竞技场（2026-06-10）→ v2 地牢探索（2026-06-26，已废）→ **v3 开放生存（本案）**。
> 定位：第二循环已从"给第一循环套一层局外壳"成长为**核心游戏循环本身**——类饥荒生存 + 帕鲁式宠物劳作 + 大陆阶段解锁。局外元层（存档 / 编队 / 带入带出 / 永久损失 / 复活道具）沿用 v1/v2 不变；局内由"地牢"换成"开放生存大地图"。

## 0. 与第一循环的关系

- **第一循环（已落地）**：单关卡战斗闭环（抓宠 → 战斗 → 死亡回传 / 全灭判负）。死亡回传链 + 阵营系统 + 全灭判负三阻断已闭合（2026-06-25），**原样复用**。
- **第二循环（本案 v3）**：局内 = **一张手工大平图的开放生存玩法**；局外 = 元层 + 放置经营。

> v2 地牢方案（生成器 / 楼层 / 房间 / 楼梯）**整体废弃**。本案局内不再有程序化地牢。

## 1. 世界结构（局外进度）

- **4 块大陆**，每块分多个**阶段区域（stage）**。
- 初始：各大陆"阶段1"已解锁。
- **击败某阶段的 Boss → 回局外后，该大陆"阶段2"成为可选入口**（下次从局外选入）。
- Boss = **进度门**（解锁下一阶段），同时也是局内的威胁事件（见 §3）。

```
大陆A：阶段1(初始解锁) ──击败Boss──> 阶段2(解锁) ──> 阶段3 ...
大陆B：阶段1(初始解锁) ──...
大陆C / 大陆D：同上
```

---

## 2. 局内玩法（进入某大陆的某阶段）

- **手工大平图**：怪 / 资源点 / Boss 洞铺在各处（非程序生成）。
- **进图标记目标地点（任务）**：进入时系统在图上标几处"需要操作的目标"。
- **核心玩法**：边**采集**、边**捕捉**、边**完成目标任务**。
- **局内宠物劳作**：把**非出战的多余宠物**派到采集点 / 工作点 → 作任务辅助 + 在未击败 Boss 前持续囤物资（帕鲁式在场劳作）。
- **完成任务后 → 二选一出口**：
  - ① **打 Boss**：胜 → 解锁该大陆下一阶段（回局外可选入口）。
  - ② **撤离**：带本局存活宠物出局（回局外仓库）。
- **无硬胜负 / 生存式**：玩家可一直在场景游玩；**物资耗尽 = 本局自然结束**。

> **Boss 事件形态**：Boss 由"献祭（如某祭坛献 N 份某资源）/ 时间（如熬过若干昼夜）/ 完成任务"触发**降生**；降生后**在场景游荡、四处破坏**（威胁与压力）。击败 = 解锁下一阶段。

## 3. 局外（元层 + 放置经营）

### 3.1 元层（沿用，不变）
存档 / 主菜单 / 编队 / 带入带出交接 / 结算 / 复活道具 = 既有 **P0–P5** 设计，照旧（P0 已提交 `f0324cb`，仍有效）。
- `UMFSaveGame`（仓库 / 墓碑 / 道具）+ `UMFMetaSubsystem`（存读档 + `PendingLoadout`/`PendingExtraction`/`BroughtInIDs` 跨关交接）。
- **v3 增量**：SaveGame 需加**大陆/阶段解锁进度** + **局外劳作派遣分配**（见 3.2）。原 `FMFRunSnapshot`（地牢续局快照）不再需要。

### 3.2 局外宠物劳作（放置产出）
- 把仓库宠物**派到已通关（已击杀该阶段 Boss）的阶段**→ 随时间**挂机产出资源**。
- 不同阶段 / 副本的**产速、效率不同** → **通关某阶段后，该阶段变"产出农场"**。
- 形成正反馈：推进解锁更多阶段 → 更多 / 更高效的产出位 → 支撑更深探索。

## 4. 核心规则：宠物归属与风险（本案灵魂，沿用不变）

| 宠物来源 | 局内阵亡 | 撤离/通关带出存活 | 全灭 / **物资耗尽未撤离结束** |
|---|---|---|---|
| **带入老宠**（局外编队选入） | 从存档删 → 进墓碑（复活道具可救） | 写回仓库刷新快照 | 同阵亡：进墓碑 |
| **本局新抓** | 直接永久消失 | 写入仓库成为永久宠 | **直接永久消失** |

> **未撤离 = 丢**：没主动撤离（含物资耗尽被动结束）就等于"困死本局"——本局宠物按全灭/永久损失处理。这逼出"必须活着带出去才算数"的张力，是生存玩法的风险核心。

## 5. 要新建的系统（按优先级 / 分期）

| 系统 | 说明 | 阶段 |
|---|---|---|
| **掉落物系统(loot)** | 怪 / 采集掉各类物资（"肉"只是例子），通用掉落表 → 进背包资源 | **MVP** |
| **任务/目标系统** | 进图标几处目标点；完成 → 解锁"撤离 / 打 Boss"出口 | **MVP** |
| **大地图铺设** | 大平图 + 怪/资源散点（复用 `AMFSpawnAIManager` 散点摆放） | **MVP** |
| **撤离 / 打 Boss 二选一** | 完成任务后的出口分支（撤离走结算交接；打 Boss 走解锁） | **MVP** |
| **大陆/阶段解锁进度** | 4 大陆 × 多阶段 + Boss 门；SaveGame 存进度，局外选关读取 | **P2** |
| **宠物劳作（双轨）** | 局内采集点派宠 + 局外已通关阶段挂机产出（产速/效率 per 阶段） | **P2** |
| **游荡破坏 Boss AI** | 献祭/时间/任务触发降生 → 在场游荡 + 破坏 → 击败解锁 | **P2** |
| **昼夜/时间系统** | 驱动 Boss 强制降生、节奏压力 | 后置 |
| **生存资源消耗** | 物资耗尽 → 本局结束 | 后置 |

### 分期建议
- **MVP**：大图 + 铺怪/资源 + 目标任务 + 掉落物 + 撤离/打Boss二选一 + 局外元层 P0–P5（已做 P0）。先把"进图→采集捕捉做任务→撤离带出/打boss"跑通。
- **P2**：阶段解锁进度 + 宠物劳作双轨 + 游荡破坏 Boss。
- **后置**：昼夜系统 + 生存资源消耗 + 4 大陆内容铺满。

- **任务类型**：进图标记的"目标"具体做什么（清点位 / 采够量 / 护送 / 净化…）？MVP 先做最简单的"到点操作 N 处"。

- **劳作产出公式**：阶段产速/效率、派遣宠物数量/属性对产出的影响。
- **大陆/阶段数量与节奏**：4 大陆各几阶段、解锁曲线。

## 附：一句话总结

第二循环 v3 = **一张开放生存大地图**：进图边采集边捕捉边完成目标，把闲置宠物派去野外劳作囤物资，完成任务后选择撤离带宝贝回家、或挑战 Boss 解锁该大陆下一阶段；外面一层存档元层承载仓库/墓碑/解锁进度，并把宠物派到已通关阶段挂机产出——配合"必须活着带出、否则永久损失"的风险规则，长成一个类饥荒 + 帕鲁 + 梦幻西游宠物养成的核心循环。
